# Predicting Airline Satisfaction：实验方案

日期：2026-10-11。比赛：[Playground Series S6E10](https://www.kaggle.com/competitions/playground-series-s6e10/overview)。

## 目标与数据边界

预测 `satisfaction=True` 的概率，以 ROC-AUC 为主指标，Log loss 为辅助指标。提交严格遵循 `sample_submission.csv` 的 id 顺序。线上测试集没有标签，最终成绩需要 Kaggle 评测，不能用本地 AUC 代替。

保留下载数据的全部记录、字段值与标签；执行缺失、数值有限性、范围、id 唯一性和提交结构检查，不修改源数据、不删行、不截尾、不去重。实测 `Arrival Delay in Minutes` 在训练/测试中分别缺失 292/130 条，其他字段无缺失。三个树模型原生处理 NaN，延误衍生特征保留 NaN；逻辑回归基线仅在拟合分区学习中位数并加入缺失标志，作为模型内部数值编码。`id` 用于对齐和顺序诊断，不作为模型特征。服务评分 0 保留为独立值。相似原始调查的数据卡明确把 Wi-Fi 的 0 解释为不适用，不能把它自动视为最低满意或缺失；其他评分的 0 语义需以本比赛定义为准。

## 验证协议

1. 用全部 21 个原始预测字段计算重复组，同一组始终放在同一侧；不因重复或标签冲突删除记录。
2. 固定种子 20261011，按组多数标签分层，留出约 20% 作为最终独立检验。关联分析及特征设计只使用其余约 80% 开发数据的标签。
3. 开发集再按组分成约 80% 拟合、20% 调参。所有初筛和特征消融共用这一划分；这部分成绩只是筛选结果。
4. 每个树模型家族取初筛最优配置，进行相同的开发集 3 折交叉验证，保存逐行 OOF 概率、每折 AUC 和最优迭代数。类别字典、标准化器仅在拟合分区学习。折验证分区用于 early stopping，因此 OOF 是开发指标；独立留出检验提供最终泛化证据。
5. 在 OOF 上比较最优单模型与预先规定的两个/三个模型等权平均；只有平均 AUC 提高至少 0.0001 且至少 2/3 折优于最优单模型才采用融合。禁止利用留出集改变配置或权重。
6. 冻结选择后，按开发交叉验证的迭代数中位数在完整开发集拟合，评估留出集一次，报告 AUC 及 DeLong 近似 95% 区间；同时展示固定候选的留出成绩用于比较，不据此重选。
7. 最终配置在全部标注数据的 5 个预先固定折上训练，使用固定迭代数、不再 early stopping，平均测试概率。该阶段 OOF 受先前全局配置选择影响，不作为独立泛化证据。保存每折模型和重建提交所需的配置。

## 关联性与重要性

- 描述样本规模、目标比例、类别频次、评分分布、重复组和冲突标签。
- 对数值字段计算 Spearman 相关矩阵及与目标的相关性；用分箱互信息与 Cramér's V 捕获非线性和类别关联，避免仅按线性相关系数删字段。
- 计算单项评分、客户类型、出行目的和舱位的满意率及标准误；展示舱位×目的、Wi-Fi×目的、登机×Wi-Fi 等分组差异。
- 比较训练/测试分布：连续字段用 KS 距离，离散字段用总变差距离。检查 id 分段的目标比例，不把纯行号作为预测依据。
- 对冻结模型做留出集原始字段置换重要性。置换原始字段后重新生成派生特征，避免派生列保留原信息而低估重要性。强相关字段增加联合置换组；重要性是预测依赖，不能解释成因果影响。

## 特征工程候选与消融

| 特征组 | 具体构造 | 预期作用/需验证的问题 |
|---|---|---|
| raw | 21 个原始字段；评分按有序数值 | 建立可靠基准，树已能学阈值与交互 |
| service | 总体均值、最小/最大值、标准差；0、1–2、4–5、5 分计数；非零均值；数字服务/舒适/人员/地面便利四组均值及最小值；每项 0 标记；登机−Wi-Fi、座椅−娱乐等差值及相等标记 | 总体体验、短板、评分习惯与数字服务一致性；0 另行保留 |
| delay | 到达−出发延误、追回延误、合计/最大延误、准点及 15/60 分钟阈值、log1p、每千距离单位到达延误 | 捕获延误累积及相对航程负担；log 单调变换对树未必有增益 |
| interactions | 舱位×目的、客户×目的、舱位×登机、目的×Wi-Fi、客户×登机、登机×Wi-Fi、座椅×娱乐、登机×娱乐；固定年龄/距离分箱 | 表达不同群体对相同服务的不同反应，保留原始连续值 |
| all | 合并前三组 | 检验互补性，也可能冗余、增加过拟合 |
| ratings categorical | 评分作为低基数类别的对照 | 检验 0 和非单调关系的特殊性 |

先在相同 LightGBM 参数下分别检验 raw/service/delay/interactions/all，再小范围比较叶子数；在 XGBoost、CatBoost 中分别比较 raw/all。暂不堆叠大批未经验证的特征。频率编码、精确年龄/距离目标编码、评分组合目标编码可作为后续候选：目标编码必须在每个训练折内部再次交叉拟合，并在验证/测试上仅映射训练统计。当前主实验采用原生类别处理和无标签行内特征，保证方案简单且可重现。

## 模型比较

- 逻辑回归：类别和评分 One-hot、连续变量标准化，衡量加性关系可达到的水平。
- LightGBM：CPU 原生类别支持，比较叶子数 31/63/127，固定正则和早停。
- XGBoost：GPU histogram，比较深度 6/8 与原始/组合特征。
- CatBoost：GPU 原生类别处理，比较深度 7/8 与原始/组合特征。
- 以同分割 AUC 选择配置，Log loss、耗时和折间波动辅助解释。类比例若接近均衡，不默认加权或过采样。树模型适合中等维度混合表格；是否胜出由实验决定，不预设算法赢家。

研究依据补充：[Grinsztajn 等，NeurIPS 2022](https://papers.neurips.cc/paper_files/paper/2022/file/0378c7692da36807bdec87ab043cdadc-Paper-Datasets_and_Benchmarks.pdf) 的多数据集实验支持将树模型作为表格任务的强基线。其主要样本规模约一万，不能直接据此断言在本次约七十万样本上神经网络一定更差；本轮优先比较训练成本低且适配混合字段的三种提升树。[CatBoost 原论文](https://arxiv.org/abs/1706.09516) 讨论有序目标统计与有序提升，用于理解类别处理中的标签泄漏问题；本次 GPU 配置实际采用的 boosting 模式以库参数为准，并未声称显式启用 Ordered boosting。
